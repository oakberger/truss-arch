**Summary**

A short summary of the package, its purpose, and its main features.

*Truss Arch Optimizer* is a coding project developed in the course of the clas "Towards Efficient and High-Performance Computing for Engineers" at ETH Zürich. The project implements a simplified form of topology optimization using the Ground Structure Method (GSM) — specifically for arch-like structures. The goal is to generate a network of nodes and bars within a given geometry and determine the optimal truss layout by minimizing total material volume via linear programming.
The project is a basic implementation of GSM, however the code is structured with extensibility in mind, meaning it should be possible to built upon the code and add more functionality, such as more constraints (modularity and constructability, symmetry etc.) or even expand to 3D structures.
