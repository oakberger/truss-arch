Detailed Description

Central data model of the truss arch optimizer.

The TrussStructure contains all structural information needed by the optimizer and matrix builder. Responsibilities:

  • Store nodes and bars
  • Generate node grid
  • Generate ground structure (bar connections)
  • Assign loads and supports
