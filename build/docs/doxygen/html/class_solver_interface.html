Detailed Description

Interface for Linear Programming (LP) solvers.

This interface defines a standard way to interact with LP solvers such as Gurobi, GLPK, CPLEX, or HiGHS. By using this interface, the rest of the code (like the LPOptimizer or TrussStructure) can work independently of the actual solver being used.

This makes it easy to:

  • Swap solvers without changing the optimization logic.
  • Test different solvers for performance or licensing reasons.
  • Keep the code clean and modular.

Example: You can use GLPK during development (free) and later switch to Gurobi (faster) by simply swapping the implementation.
