Detailed Description

Collects the full result of the optimization process.

After solving the truss optimization problem, an instance of this class stores all relevant output: forces, volume, and status of each bar. It is returned by the optimizer (e.g., LPOptimizer) and can be passed to exporters for visualization or file output.
